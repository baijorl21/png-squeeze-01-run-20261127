Screened PNG Squeeze: a lossless screenshot re-encoder. Each screenshot is decoded to exact RGBA pixels, then screened across colour forms (palette, grey, grey+alpha, RGB, RGBA, single-colour transparency) and per-row filter strategies; the best streams are deflated at level 9 and re-deflated with a built-in optimal-parse deflater, and the smallest valid PNG wins. All choices are fixed functions of the input bytes, so two runs write the same bytes.

## Run it

```sh
node main.ts
```
